About this tool

Nape Pro Configurator manages jerrymk’s custom firmware for the Keychron Nape Pro trackball. Configure eight profiles with eight layers each, button actions, DPI, orientation, trackball scrolling and LED colors. The Device tools flash firmware over USB and back up, adopt or restore stock user data.

Use desktop Chrome or Edge and the trackball’s USB data cable. All device communication and file processing happen locally in your browser. This is an independent project, not an official Keychron application.
